# 午餐選困互助會 — 安裝說明

三個人共用一本帳，各自手機都能記，資料存在你們自己的 Google Sheet。

檔案：

| 檔案 | 放哪裡 |
|---|---|
| `Code.gs` | Google Apps Script |
| `index.html` | GitHub Pages |

---

## 一、建 Sheet 和後端（只要做一次，一個人做就好）

1. 開一個新的 Google 試算表，隨便命名（例如「午餐帳本」）。**分頁不用自己建**，程式第一次跑會自動建好。

2. 在那張試算表上，選 **擴充功能 → Apps Script**。

3. 把編輯器裡原本的內容全部刪掉，貼上 `Code.gs` 的全部內容。

4. 改第 14 行的通關密語：

   ```js
   var SECRET = 'CHANGE-ME-隨便打一串';
   ```

   改成你們自己的隨機字串，例如 `lunch-x7k2m9-guild`。**不要用生日或公司名**——知道網址又猜到密語的人就能寫入。

5. 存檔（Ctrl+S / Cmd+S）。

6. 右上角 **部署 → 新增部署作業**：
   - 齒輪選 **網頁應用程式**
   - 說明：隨便填
   - **執行身分：我**
   - **具有存取權的使用者：任何人**  ← 這個一定要選「任何人」，選「僅限自己」的話另外兩支手機會連不上
   - 按「部署」

7. 第一次會跳授權，按 **審查權限 → 選你的帳號 → 進階 → 前往「未命名專案」(不安全) → 允許**。這是 Google 對自己寫的腳本的標準流程，不用擔心。

8. 複製最後給你的 **網頁應用程式網址**，長這樣：

   ```
   https://script.google.com/macros/s/AKfycb..../exec
   ```

   結尾一定要是 `/exec`。這串網址和上面的密語，等一下三支手機都要填。

> 之後如果改了 `Code.gs`，記得要 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。直接存檔是不會生效的。

---

## 二、放上 GitHub Pages

1. 開一個新的 repo（public 或 private 都行，Pages 需要 public 或付費方案）。

2. 把 `index.html` 丟進去，commit。

3. **Settings → Pages → Source 選 `Deploy from a branch`，branch 選 `main` / 根目錄 `/`**，存檔。

4. 等一兩分鐘，網址會是 `https://yulunyeh0731.github.io/<repo名>/`。

`index.html` 是單一檔案，字型、場景、所有像素圖都內嵌在裡面，沒有其他相依檔案。

---

## 三、三支手機各自安裝

每個人做一次：

1. 用 **Safari**（iPhone）開上面那個 GitHub Pages 網址。
2. 貼上 **API 網址** 和 **通關密語**，按「連線」。
3. 連上之後會出現「你是誰」，選自己，按「就是我」。
4. 按 Safari 下方的 **分享 → 加入主畫面**。

加到主畫面之後會是全螢幕、有圖示，跟一般 App 一樣。

> Android 用 Chrome 開，選單裡的「安裝應用程式 / 加到主畫面」。

## 四、怎麼用

**遭遇** — 先在下面「口袋名單」把常吃的店加進去，然後按「遭遇一家店」抽。抽的時候會自動跳過最近吃過的（天數在設定裡調）。抽到滿意就按「就這家」，會直接帶到記錄頁。

**記錄** — 誰都能記。填日期、店家、誰先付的、三個人各自多少（沒吃的留空）。如果是均分，填總額按「均分」，餘數會算在付錢的人頭上。店家名字打完圖示會自動判斷，不對就點左邊那顆改。

**隊伍** — 本期的收支和全部紀錄。點任何一筆可以進去改或刪。

**清算** — 算出誰要轉給誰（三個人最多兩筆）。按「複製戰報」貼進 LINE 群，收到錢之後按「關帳」，那批紀錄就封存，開始新的一期。誰都可以按關帳。

**統計** — 近 8 週長條圖，或切到月曆看每一天。月曆一天可以有多筆，超過兩筆會顯示 `+n`，點進去看細節。

---

## 五、同步是怎麼運作的

- 打開 App、從背景切回來、每次寫入之後都會自動同步
- 右上角那顆會顯示狀態：`已同步 12:05` / `未送出 2` / `同步失敗`
- **點它可以手動同步**，旁邊的齒輪是設定
- **沒訊號也能記**。寫入會先存在手機裡排隊，連上網之後自動送出去。地下室美食街照用
- 三個人同時記不會互相蓋掉：每筆紀錄有自己的 ID，同一筆以最後改的為準
- 刪除是標記刪除，Sheet 裡那一列還在（`deleted` 欄 = 1），所以誤刪救得回來

## 六、可能會遇到的狀況

**連不上 / 同步失敗**
- 網址結尾是不是 `/exec`？（不是 `/dev`）
- 部署時「具有存取權的使用者」有沒有選「任何人」？
- 密語和 `Code.gs` 裡的 `SECRET` 是不是完全一樣（含大小寫）？

**改了 Code.gs 沒生效** — 要重新部署新版本，不是存檔就好，見第一節最後那段。

**想手動改資料** — 直接編輯 Google Sheet 就行，但改完要把那一列的 `updatedAt` 改成一個更大的數字（現在的毫秒時間戳，例如 `1786500000000`），不然手機端會認為自己的版本比較新而蓋回去。

**想重來** — 把 Sheet 裡 `entries` 分頁第 2 列以下全部刪掉，然後三支手機都到設定按「儲存並同步」。

**備份** — 設定裡有「匯出備份 JSON」。Sheet 本身也是備份，Google 有版本紀錄。

---

## 七、安全性

密語放在網址參數裡，所以：知道 GitHub Pages 網址 **而且** 知道密語的人，才能讀寫你們的帳本。對三個人的午餐帳來說夠用，但不要拿這套去存真的敏感資料。

Sheet 本身還是只有你的 Google 帳號能直接打開。
